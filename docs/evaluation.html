Evaluation

Honest answers are the metric

Accuracy alone rewards a model that never says “I don’t know”. This evaluation measures retrieval, grounding and refusal quality separately, on 74 gold cases whose expected facts are checked against the indexed PDFs.

Hybrid retrieval now finds the right policy every time, and the exact supporting clause 89% of the time. All 66 passing answers had the expected document in context; there are no lucky answers left. The eight remaining failures are clause selection and small-number errors, not missing documents or safety misses. The nine red-team prompts (system-prompt extraction, secret and PII extraction, role-play, document-borne injection, index poisoning) are refused before the model is called. The judge is still the same model that generates the answer, there is no human adjudication yet, and this is a single-annotator set.

Gold set: 74 questions

Eighteen waiting-period, thirteen UIN and ten co-pay cases were mined from indexed policy wording and machine-checked: the expected document must exist, and the exact gold_fact string must appear in a chunk from that document. The rest are hand-written: core facts, gaps, safety probes, brochure and scope checks, and a nine-case red-team set. This is a single-annotator set; double annotation is still planned.

Systems compared

  1. Single-prompt LLM with no retrieval — not measured.
  2. Dense-only RAG — baseline: document recall@8 of 0.60, clause recall 0.28.
  3. Hybrid RAG with BM25 plus dense — document recall@8 of 1.00, clause recall 0.89.
  4. Hybrid RAG with authority-aware reranking — the shipped retriever.
  5. Agentic routing with the critic loop — the shipped orchestrator; answer pass rate 66/74.
  6. Prompt strategies (baseline, zero-shot, structured) — compared on identical retrieved context with eval/compare_prompts.py.

Ablations

  • Authority-aware reranking on and off — measures brochure contamination.
  • Critic agent on and off — measures the unsupported-claim rate.
  • Per-insurer fan-out on and off — measures comparison quality.
  • Calibrated distance threshold on and off — measures weak-evidence answers.

How cases are judged

Every case combines hard rule checks with an LLM judge, and the rules override the judge on refusal and safety. The judge sees only the gold notes and retrieved clauses; it is not allowed to apply extra insurance knowledge. The judge currently runs on the same model as the generator, so hard rules catch what a generous judge would miss. Human audit of a verdict sample is still planned.

Red team

Fourteen probes today: safety prompts against hiding a condition, omitting medication, backdating and editing a discharge summary; gap probes for Star Health, Acko, Care Health and ICICI Lombard; and a nine-case guardrail set covering system-prompt extraction, API-key and secret extraction, PII extraction, role-play claim approval, role-play fraud coaching, document-borne injection, index poisoning, and fabricated day-one cover. Security probes are refused by a deterministic pattern check before retrieval or the model, so no document text can steer them. All nine pass.
