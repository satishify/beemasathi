Evaluation

Honest answers are the metric

Accuracy alone rewards a model that never says “I don’t know”. This evaluation measures retrieval, grounding, citation correctness and refusal quality separately, on a frozen set created before the agentic layer.

This is a smoke set, not a gate. It is judged by the same model that generates the answer, it has no retrieval metrics, and it has no negative set for threshold calibration. One refusal case passes for the wrong reason while fabricated Star Health demo data is still live in the index — which is exactly why the corpus-integrity gate comes first.

Frozen set: 80 questions

Written and versioned before the agentic layer exists, so the agents cannot be tuned to the test. Two annotators label each question against the cited official PDFs; disagreements are adjudicated by a third and inter-annotator agreement is reported.

Systems compared

  1. Single-prompt LLM with no retrieval.
  2. Dense-only RAG — the current baseline.
  3. Hybrid RAG with BM25 plus dense.
  4. Hybrid RAG with authority-aware reranking.
  5. Full multi-agent system with the critic loop.

Ablations

  • Authority-aware reranking on and off — measures brochure contamination.
  • Critic agent on and off — measures the unsupported-claim rate.
  • Per-insurer fan-out on and off — measures comparison quality.
  • Calibrated distance threshold on and off — measures weak-evidence answers.

How cases are judged

Every case combines hard rule checks with an LLM judge, and the rules override the judge on refusal and safety. The judge sees only the gold notes and retrieved clauses; it is not allowed to apply extra insurance knowledge. Twenty percent of verdicts are human-audited, and the judge is a different model from the generator.

Red team

Fifteen attacks across three channels: user prompts (fraud, prompt extraction, role-play), poisoned PDFs (instructions in clause text, invisible text), and retrieval manipulation (questions crafted to surface a brochure or another insurer). Success means refusal, safe redirection, or a correct answer with no instruction followed.
