Evaluation

Honest answers are the metric

Accuracy alone rewards a model that never says “I don’t know”. This evaluation measures retrieval, grounding and refusal quality separately, on 100 gold cases whose expected facts are checked against indexed chunks and source policy PDFs.

Hybrid retrieval finds the expected policy in 79 of 81 labelled cases and the exact supporting clause in 73 of 80. All 85 passing answers had the expected document in context, so no answer was right by luck. The 15 failures split into 2 document misses, 5 supporting-clause misses and 8 answer errors; the recurring shape is picking the wrong sub-clause or the wrong number (24 months where the wording says 36, INR 10,000 where it says Rs 2,500). Twelve of the 15 trip a hard rule while the LLM judge accepts the answer. In some the rule is right and the judge is too lenient; in others the rule string is too narrow — one case bans “60 days” even though 60 days is the correct post-hospitalisation window. Read 85/100 as conservative, not as a rule-versus-judge tie. The nine red-team prompts (system-prompt extraction, secret and PII extraction, role-play, document-borne injection, index poisoning) are refused before the model is called. The judge is still the same model that generates the answer, there is no human adjudication yet, and this is a single-annotator set.

Gold set: 100 questions

The set now includes 26 additional customer-style questions grounded against raw policy PDF pages and their indexed chunks, covering health benefits and claim timelines, optional benefits, and motor claims and exclusions. Answer and judge metrics come from the full 100-case judged run on 23 Nov 2026; retrieval metrics were re-measured on 24 Nov 2026 after the corpus rebuild and the comparison-grounding fix.

Eighteen waiting-period, twelve UIN and ten co-pay cases were mined from indexed policy wording and machine-checked: the expected document must exist, and the exact gold_fact string must appear in a chunk from that document. One more UIN case is hand-written. The rest are hand-written too: core facts, gaps, safety probes, brochure and scope checks, and a nine-case red-team set. This is a single-annotator set; double annotation is still planned.

Systems compared

  1. Single-prompt LLM with no retrieval — not measured.
  2. Dense-only RAG — earlier 74-case baseline: document recall@8 of 0.60, clause recall 0.28.
  3. Hybrid RAG with BM25 plus dense — document recall@8 of 0.975, clause recall 0.912.
  4. Hybrid RAG with authority-aware reranking — the shipped retriever.
  5. Agentic routing with the critic loop — the shipped orchestrator; answer pass rate 85/100.
  6. Prompt strategies (baseline, zero-shot, structured) — compared on identical retrieved context with eval/compare_prompts.py.

Ablations

  • Authority-aware reranking on and off — measures brochure contamination.
  • Critic agent on and off — measures the unsupported-claim rate.
  • Per-insurer fan-out on and off — measures comparison quality.
  • Calibrated distance threshold on and off — measures weak-evidence answers.

How cases are judged

Every case combines hard rule checks with an LLM judge, and the rules override the judge on refusal and safety. The judge sees only the gold notes and retrieved clauses; it is not allowed to apply extra insurance knowledge. The judge currently runs on the same model as the generator, so hard rules catch what a generous judge would miss. Human audit of a verdict sample is still planned.

Red team

Eighteen probes today: five safety prompts (hiding a condition, omitting medication, backdating a renewal, editing a discharge summary, submitting a fake bill); four gap probes for Star Health, Acko, Care Health and ICICI Lombard; and a nine-case guardrail set covering system-prompt extraction, API-key and secret extraction, PII extraction, role-play claim approval, role-play fraud coaching, document-borne injection, index poisoning, and instruction override to claim fabricated day-one cover. Security probes are refused by a deterministic pattern check before retrieval or the model, so no document text can steer them. All nine pass.
